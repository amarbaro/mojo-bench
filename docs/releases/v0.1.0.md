# mojo-bench v0.1.0

**Released:** 2026-11-04 · **Commit:** `6b3f6fb` · **Previous:** first release

## What it does

Benchmark harness for Mojo that reports statistics, not one number: warmup, auto iteration count,
median, MAD, min, p95, seeded 95% bootstrap CI, outlier count, and `compare()` that says
"no difference" when the CIs overlap. 211 lines, no dependency beyond the stdlib. Every statistic is
checked bit for bit against a Python reference (`tools/oracle.py`) on 3117 seeded cases.

A Mojo library for Linux (Mojo 1.2). Use it from source with `mojo run -I path/to/mojo-bench/src app.mojo`.

## Highlights

- One call gives median, MAD, min, p95, a 95% CI and an outlier count, not one number.
- `compare()` says "no difference" when the CIs overlap, so a noisy 3% never reads as a win.
- Statistics match a Python reference bit for bit; the bootstrap runs about 115x faster than that reference.

## Known limits

- CPU timing only: no GPU sync, no hardware counters.
- `stats` and `compare` need a non-empty vector.
- The CI workflow (`.github/workflows/ci.yml`) has not run on GitHub: there is no remote. UNVERIFIED there.
- Statistics are of the median; there is no mean or stddev.
